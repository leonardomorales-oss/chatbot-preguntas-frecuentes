# Chatbot de preguntas frecuentes

Chatbot con respuestas predefinidas y una interfaz de conversación.

## Tecnologías

- HTML
- CSS
- JavaScript

## Instalación y ejecución

Sin dependencias: abre `index.html` en el navegador.

## Uso

Escribe una pregunta conocida y envíala con el botón o con Enter.
